# Day 02 — Ticket analysis, reproduce and understand

## Task

1. **Ticket analysis:** take 5 tickets from the training backlog, write the three-sentence analysis (what it asks, what's ambiguous, first step), use Claude to find gaps and draft clarifying questions, and compare with a partner's analysis.
2. **Reproduce and understand:** take one seeded bug ticket, get the app running locally, reproduce the bug and write exact repro steps into the ticket.
